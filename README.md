



# Polarization-guided diffusion model for physically inspired underwater image descattering 

---

## 🚀 **Installation & Usage**

### 1. Clone the Repository

```bash
git clone https://github.com/lee-lucia/polarization_descattering.git
cd polarization_descattering
pip install -r requirements.txt
```

### 2. Download the Dataset

Note: Currently, only the test dataset is available. The training dataset is being organized. Stay tuned!


### 3. Run the Demo

Once everything is set up, run the demo script:

```bash
python simple_test.py -opt options/test/test.yml -gpu_id 0
```
